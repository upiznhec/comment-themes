---

Please set up the comment themes workflow for me. Download https://github.com/upiznhec/comment-themes (or its ZIP if git is not available), read its AGENTS.md and follow it. ## After setup: example requests

Send a request like these whenever you want comments sorted, with your own links:

- Sort the comments on these posts into themes: [link] [link]. They are my posts.
- What are people asking under this video? [link] It is not mine.

After an analysis, ask your own questions, for example: How many people asked about the price?

The first time a request needs a key, or a choice about how to read your own posts, the agent asks for it. If it can use the browser you are already logged in to, it opens the pages and does the clicks: you only log in, then make and copy the key. On Facebook and Instagram you do every click yourself.
